# CLAUDE.md

Production repo for the bilingual course "分布式系统从零读懂 / Distributed Systems, Read Closely", a self-study path
through MIT 6.5840 (Spring 2026). Use the course-studio skill for any episode or site work.

Layout, commands and pitfalls met so far: @README.en.md

## Rules

- **Video-first (2026-10-19).** Each episode ships as video + 课件 (slides) only: no lab page, flowchart or project atlas.
- **Silent first.** Build timelines with `silent_timeline.py`, not `tts.py`, until the user asks for narration.
  Scenes time off beats, so switching to TTS later only needs tts → build → record → slides → sync.
- **Quality over length.** One mechanism and one running example per episode; split into parts (`ep16a`, `ep16b`)
  whenever an episode gets dense. Before producing each episode, show the user the outline and the split.
- **Keep `6.5840/` checked out at `513cac0`** (git://g.csail.mit.edu/6.5840-golabs-2026, a submodule). Videos quote it
  by `file:line`, verbatim, cut by script. Moving the pin is the user's decision.
- **No lab solutions.** Never put an implementation of a lab (coordinator, Raft, kvraft, shardkv) in this repo or on
  screen. Quote only code the course hands out (skeleton, tester, labrpc, mrapps) and the papers.
- **Private lab implementation (approved 2026-10-19).** Episodes about code the student writes (Raft, kvraft,
  shardkv, the MapReduce coordinator) get their real runs from a private implementation kept **outside this repo**
  (`~/Documents/ChatGPT/mit-labs-private`, a copy of `6.5840/` at `513cac0`). Only its runs, traces and numbers go
  into a video; its code never appears on screen, in the 课件 or in this repo.
- **Real runs only.** Numbers on screen come from running the code (`data.py` per episode); label anything worked out
  by hand as such.
- **Bilingual:** every learner-facing string gets Chinese and English in the same edit.
- The episode list lives in `episodes/plan.py`; regenerate planned entries with `python3 episodes/gen_course.py`.
  `site/content/` is generated by `python3 site/dev/sync_content.py epNN`.
- Never write API keys into any file in this repo (the Gemini key lives in `~/.config/course-studio/.env`).
- macOS has no `timeout`. The site runs with `cd site && npm start` on port 7880.
